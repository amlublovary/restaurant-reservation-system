# restaurant-table-reservation
“Restaurant Table Reservation" is a web application that enables visitors to reserve online a table at any restaurant, bar or café, and notify the manager to prepare the tables and meals in advance.

This application aims to enhance customer service by offering a comprehensive view of available tables in the restaurant before arriving to the venue, allowing guests to choose their preferred seating in advance, explore the restaurant's menu, and add their reservation to their calendar.
Additionally, it alleviates the manager from the need to handle each reservations individually, saving them time on note-taking, providing an overview of upcoming bookings, and allowing to reserve tables and prepare the kitchen staff in advance.
Developed using common web standards such as HTML, CSS, JavaScript, PHP and SQL.
